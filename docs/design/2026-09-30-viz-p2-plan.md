# P2 plan — inspect & style (`netstead.viz`)

Status: **done** (#194) · Parent: [network viewer PRD](2026-09-30-network-viewer-prd.md)

Builds on P1's binary render path. Incremental, each verifiable:

1. **Control panel + layer toggles** — a left panel: show/hide each layer (links, nodes,
   labels, selection) + opacity. (Increment 1)
2. **Attribute styling** — "color by": `none` (default slate), `facility_type` (categorical
   palette + legend), `lanes` (continuous ramp + legend). Colors built as per-VERTEX binary
   arrays from `network.attrs.json` (facility_type) / lanes buffer; restyle live, no reload.
   (Increment 1)
3. **Detail table** — click a link → fetch the full attribute row from a DuckDB-backed
   `/api/link/{id}` endpoint → show in a virtualized table panel (basic tooltip stays the hover
   path). (Increment 2)
4. **Directional offset** — `PathStyleExtension.getOffset` with a signed per-link offset so
   opposing one-way links / carriageways separate; offset the pick pass too. (Increment 2)
5. **O/D + selection node highlighting** — generalize the gore/merge anchor markers into a
   reusable "highlight nodes with roles" layer (origins/destinations). (Increment 3)

Principles carried from the PRD: per-feature binary attributes; stock deck.gl layers +
`PathStyleExtension`; heavy work server-side; legend auto-generated from the active style.
